# Changelog

## 0.2.0 — 2026-10-25

- Promote 0.2.0-beta.1 functionality for a full, non-prerelease release.
- Align package and card versions at 0.2.0 and update installation and release documentation.
- Preserve existing compatibility limits; no equipment-control behavior changes.

## 0.2.0-beta.1 — 2026-10-15

- Add a visual editor with native Home Assistant entity, icon and option selectors.
- Configure labels, local photo, accent, card/panel layout and navigation without YAML.
- Hide unassigned equipment and allow explicit section visibility choices.
- Validate entity domains, image paths and navigation links.
- Show explicit temperature units and honor heater temperature limits and steps.
- Preserve confirmations, live status, service-mode checks and failed-command feedback.
- Add automated configuration, editor and command-routing tests.
- Add HACS metadata, draft-release automation, examples and contribution templates.

First public beta. Tested setup: Hayward OmniPL with OmniLogic Local 2.0.2. Other compatible entity mappings are available for experimentation; universal controller support is not claimed. Not listed in the HACS default store.
